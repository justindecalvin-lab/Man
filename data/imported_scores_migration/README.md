# Imported Scores & Migration Repository Dataset
Source Repository: https://github.com/justindecalvin/Scores

This directory contains the backed-up migration file and remaining midterm scores imported from the external `Scores` repository:
- `Stanbax_Complete_Migration_88_Scholars_Logins_Subjects_2026-10-29 2.json`: Master backup containing the 88 scholars, subjects, and institutional setup.
- `Jss1.csv`: Midterm test scores for JSS 1.
- `jss2_scores.json`: Midterm test scores for JSS 2.
- `Kg1.csv`: Midterm test scores for Kindergarten 1.
- `Kg2.csv`: Midterm test scores for Kindergarten 2.
- `Pry1.csv`: Midterm test scores for Primary 1.
- `Pry.json`: Midterm test scores for Primary 2 & 3 scholars.
- `ss1_scores.json`: Midterm test scores for SSS 1 (first two tests used).
- `Ss2art.csv`: Midterm test scores for SSS 2 Arts & Commercial.
- `Ss2_science.csv`: Midterm test scores for SSS 2 Science.
- `ss3_scores.json`: Midterm test scores for SSS 3 scholars (new accounts created).

This folder is strictly isolated from core application logic and tracked as the imported data source.
